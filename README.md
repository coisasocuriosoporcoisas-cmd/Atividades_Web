# Atividades_Web
As pastas acima representam cada atividade solicitada ao professor da respectiva materia voltada ao desenvolvimento web.
Cada aplicação foi adicionada conforme a data maxima solicitada pelo Orintador.


# O que cada aplicação aborda?

Cada aplicação engloba conceitos básicos das linguagens mais ultilizadas na em aplicações web, cada uma envolve um trabalho que medir o nível apresentado ao decorrer das aulas.
Iniciando com pagínas básicas usando somente HTML e sua TAG iniciais, há incoporação do CSS, com a adição de pagína estilizadas é retirando a aparência siploria imposta anteriomente.
## conceitos básicos aplicados:
### Em HTML:

- Etrutura básica de um arquivo HTML
- TAGS de titúlos **H1, h2,h3,h4,h5,h6**
- TAGS de marcação de palavras
